# Stripe payments demo (sample store)

A small Node and Express store for a made up product called Fieldnote, wired to Stripe in test mode. It sells a one-time guide and a Pro subscription with monthly and yearly prices through Stripe Checkout, opens the Stripe customer portal so subscribers can manage or cancel, and records every order in a simple orders table that the webhook updates to paid, active, renewed or canceled. The webhook checks Stripe's signature and ignores repeated events, so a retried delivery never double counts.

To run it with a real test account, set `STRIPE_SECRET_KEY` to an `sk_test_` key, run `npm install` and `npm run setup` to create the products and prices by lookup key, start `stripe listen --forward-to localhost:4242/webhook` and put its `whsec_` secret in `STRIPE_WEBHOOK_SECRET`, then `npm start` and pay with card 4242 4242 4242 4242. `npm test` runs ten end to end checks against stripe-mock, Stripe's official API mock, so no account is needed for the tests. The server refuses live keys on purpose.
